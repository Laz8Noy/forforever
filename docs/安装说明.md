# Forforever v0.1.2 安装说明

## 安装 APK
1. 把 `Forforever-v0.1.0.apk` 传到安卓手机（微信/QQ/网盘/数据线均可）。
2. 点击安装。系统提示「未知来源」时，允许本次安装即可（本包为 debug 签名，未上架商店）。
3. 要求 Android 6.0（API 23）及以上。

## 第一次打开
1. 引导页会教你创建 DeepSeek API key：点「打开 DeepSeek 开放平台」→ 注册/实名 → 创建 API key → 充值少量金额（10 元能用很久）。
2. 回到 App 粘贴 key → 测试连接 → 创建第一个人物（名字 + 人设）→ 开始聊天。
3. key 与全部数据只存在手机本地：key 在安卓系统 Keystore 中，日记等数据在 app 私有目录；已关闭系统备份（adb/云备份不会带走数据）。卸载会清空，换机前请在 设置 → 数据 导出备份（安卓备份不含 key，重装后需重填）。

## 核心玩法
- **左滑**聊天页呼出抽屉：顶部人物卡、偷看日记入口、全部对话。
- **离线 3 小时**再回来：ta 会自动整理两级记忆（用户记忆 / 角色记忆）并写一篇人设口吻的日记（需 App 开着）。
- **偷看日记**：手动输入「确认偷看ta的日记」才能看。
- **面向 AI 的记忆**：设置里查看需双重确认；可编辑/置顶/停用/删除。
- 每个对话可选思考强度（关/低/高/满）与模型（flash / v4-pro）。
- 设置里可换浅色/深色主题、照片背景、上下文预算（默认 128K，最大约 900K）。

## 遇到问题怎么反馈
设置 → 诊断 → 查看/导出日志（或直接把备份 zip 发给开发者）。日志只含错误元数据（时间/级别/标签/模型等），不含聊天内容与人设。

## 费用与限制（如实说明）
- 按 DeepSeek 官方 API 按量计费：flash 闲时（北京时间 00:30–08:30）输入 1 元/输出 4 元每百万 tokens，高峰翻倍；v4-pro 约 4.5 倍。聊天页会显示每轮估算/实际费用。
- DeepSeek 官方 API 有内容审核，露骨内容会被平台拒绝，App 无法绕过。
- 第一版记忆收集在 App 前台执行；不做系统级后台常驻。
